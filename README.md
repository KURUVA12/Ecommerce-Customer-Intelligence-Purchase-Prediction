# E-Commerce Customer Intelligence and Purchase Prediction

## 1. Project Overview

This project is about understanding customer behaviour in online shopping and predicting whether a customer will purchase a product or not.

It uses Python, data analysis, graphs, and machine learning algorithms to study customer shopping activities and make predictions.

## 2. Project Objectives

- To understand customer shopping behaviour.
- To analyse customer shopping data.
- To find useful patterns using graphs and charts.
- To predict whether a customer will purchase a product.
- To compare different machine learning algorithms.
- To identify the best-performing model.

## 3. Dataset Information

- Total Records: 7,000
- Total Columns: 15
- Data Type: E-commerce shopping data

Some important columns include:

- Product Price
- Page Views
- Session Duration
- Device Type
- Customer Type
- Region
- Product Category
- Added to Cart
- Purchase

## 4. Technologies Used

- Python
- Spyder
- Anaconda
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 5. Project Workflow

1. Load the dataset.
2. Understand the data.
3. Check missing and duplicate values.
4. Clean and prepare the data.
5. Perform Exploratory Data Analysis (EDA).
6. Create graphs and charts.
7. Train machine learning models.
8. Compare model performance.
9. Select the best model.

## 6. Machine Learning Algorithms

Four algorithms were used in this project:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Decision Tree
4. Naive Bayes

## 7. Model Results

Logistic Regression achieved the highest F1-score among the four tested models.

- Accuracy: 63.43%
- Precision: 39.73%
- Recall: 59.71%
- F1-Score: 47.71%

This project helps us understand online customer behaviour and predict customer purchases using machine learning. By comparing four algorithms, Logistic Regression was selected based on its F1-score.
